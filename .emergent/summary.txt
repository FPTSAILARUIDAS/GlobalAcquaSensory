<product_requirements>
The goal was to build a full-stack web application, the Global Acqua Sensory App, for Global Acqua Pvt Ltd to digitize their water sensory analysis process.

**Core Functionality:**
-   **Sensory Evaluation:** Users can submit sensory analysis results for water samples. The evaluation focuses on 'Appearance', 'Odour', and 'Taste', with a simple 'IN' or 'OUT' conclusion. If 'OUT', the user must select a reason from a predefined list, which includes an editable 'Other' option.
-   **Data Entry Form:** The form must capture details like panelist name, number of panelists, product type (e.g., Raw Water, Finished Goods), product variant (conditional on product type), batch code, and testing completion date/time. The product type and variant fields also support an editable 'Other' option.

**User Roles & Authentication:**
-   **Super Admin:** Can create/delete user accounts, view all sensory analysis sessions from all users, and view/download detailed and summary reports. The default 'admin' user was to be removed, allowing admins to be created dynamically.
-   **Standard User (Panelist):** Can only create or join collaborative sessions to submit their analysis results. They cannot view historical data.

**Reporting & History:**
-   **Admin Dashboard:** Admins have a view of all sessions, with search functionality (by date, batch code, panelist name) and a scrollable history.
-   **Reports:** For each session, admins can view a detailed, single-page printable report or a tabulated summary report for multi-panelist sessions. Reports must show a final 'ACCEPTED' or 'REJECTED' conclusion and be downloadable as a PDF.

**Branding:**
-   The application must display the company name Global Acqua Pvt Ltd with the tagline Sensory Quality Control. The title of the main process is Sensory Analysis.
</product_requirements>
